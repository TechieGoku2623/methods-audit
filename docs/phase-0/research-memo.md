# Phase 0 research memo — methods-audit

This memo is generated by `research/phase0/render_docs.py` from harness
`results.json` files. Narrative is the template; every quantitative claim is
substituted from those files. Re-run `make research` after changing a harness.

**Safety.** This project is research / decision-support tooling. Completeness
is not quality, novelty, or a recommendation to retract. Unfilled fields stay
missing. Nothing is inferred. Phase 0 uses designed PMC-OA-style XML snippets,
not a live PMC dump.

---

## §1 Problem statement

CRISPR methods sections are where a paper either becomes reproducible or
becomes a story. The missing cell is usually a guide sequence, a genome
build, or a named cell line. Reviewers score "complete enough" by vibe.
Journals already publish reporting checklists; they do not publish a
span-grounded extraction of those checklists, and they do not separate
"the field was filled" from "the filled value is internally consistent."

The people who pay for that gap are the labs that try to repeat the figure
and the editors who inherit a methods paragraph that cites "as previously
described." Inferring the missing guide from the gene name is the failure
mode this repo refuses.

This repo defines a replication schema first, extracts only what it can
quote, scores completeness over that structure, and runs the cross-checks
(guide vs gene, cell-line identity) that a completeness number will hide.

## §2 Prior art

| Tool | What it does | Gap |
| --- | --- | --- |
| [MDAR Framework](https://elifesciences.org/articles/57303) (Chambers / Macleod 2020) | Materials–Design–Analysis reporting checklist | A checklist, not an extractor |
| Nature Portfolio Reporting Summary | Author-filled genome-editing boxes | Honor system; no span grounding |
| [ARRIVE 2.0](https://arriveguidelines.org/) (Percie du Sert 2020) | Animal-experiment reporting | Conditional animal fields only |
| [MIQE](https://doi.org/10.1373/clinchem.2008.112797) (Bustin 2009) | qPCR reporting | Assay-conditional; not CRISPR-specific |
| [CRISPOR](http://crispor.tefor.net/) (Concordet & Haeussler 2018) | Guide design + off-targets | Does not read papers |
| [Cellosaurus](https://www.cellosaurus.org/) (Bairoch 2018) | Cell-line identity | A catalog, not a methods auditor |
| [PubTator / BioBERT](https://www.ncbi.nlm.nih.gov/research/pubtator/) | Biomedical NER | Entities ≠ schema fields; will infer |
| SciScore / MDAR automations | Automated checklist hints | Closed or not span-cited; quality mixed with presence |

Something already "solves" CRISPR reporting: the Nature summary and MDAR
do, as checklists. Another engine is still worth building because
(1) a filled box without a quote is not audit evidence, (2) a complete
report can still name a guide that does not target the stated gene, and
(3) INT-407 will pass a completeness score and fail a Cellosaurus check.
The product of this repo is the extraction-plus-checks, not a new impact
factor for methods.

### 4.1 Schema before extractor

Options: extract free text and invent fields later; start from MDAR/Nature
RS/ARRIVE/MIQE/CRISPOR and freeze 25–40 fields.

Criterion: every field has a need (required / optional / conditional) and a
citation. Conditional fields attach only when a trigger is extracted, never
when it is guessed.

Measurement: `src/methods_audit/fields.py` (32 fields). Not a runtime
number.

Decision: **32-field schema, defined first.** Required core is the twelve
always-on fields. Conditionals: cell-line RRID, HDR donor pair, ARRIVE
animal trio.

Criterion: value agreement between two committed gold passes on 15
papers is the honest upper bound.

## §5 Evaluation design

Hold-out (Phase 3, not run here): a pinned PMC OA CRISPR methods slice
with hand-annotated gold spans.

Metrics, declared before any live pull:

- Per-field precision, recall, F1 against gold spans
- Median field F1 (leaderboard gate: 0.70)
- Completeness score vs gold completeness (presence, not quality)
- Guide-vs-gene and cell-line identity check precision
- Annotator agreement as an accuracy ceiling
- Baseline: regex-only extractor (this Phase 0 system)
- Second baseline: "fill every field from the title" (must lose)

Split: pinned, committed paper ids. Seed 0. No random reshuffle in CI.

**Failure condition (written before the answer):** the project fails if, on
the live hold-out, median field F1 is below 0.70 **or** any filled field
lacks a quote that occurs in the source **or** a missing field is inferred
**or** the guide-mismatch / bad-cell-line checks do not fire on the
designed cases.

Phase 0 median field F1 against the designed probe set: 1.000.

Median field F1 is 1.000 (>= 0.70). A completeness leaderboard on this extractor is defensible on the probe set.

Annotator value agreement (accuracy ceiling): 0.981.

- API RTT: unmeasured

Unmeasured: PMC OA bulk download wall-clock, human annotation minutes per
paper, editor time saved. The measurement that would settle ingest cost is
a timed download of a CRISPR-query OA slice on a 4-core machine, recorded
as seconds and peak RSS.

## §7 Risks

| Risk | Type | Mitigation or acceptance |
| --- | --- | --- |
| Probe-set gold is designed, not OA-annotated | Data | Accepted for Phase 0. Memo and harness READMEs say so. Phase 3 replaces the 50. |
| Median field F1 below 0.70 | Technical | Gate is written before the answer. Memo states defensibility from the harness. |
| Extractor infers a guide | Technical | Unquoted fill is a failed unit test. Indirect.xml is the teaching case. |
| Completeness scored as quality | Scope | Score module refuses quality language. Guide-mismatch stays complete and fails a check. |
| Cell line synonym missed | Data | Committed list, not a live Cellosaurus pull. Live synonym coverage is unmeasured. |
| Output read as a misconduct finding | Legal | Disclaimer on CLI, README, memo. Completeness ≠ retraction. |
| Cache treated as a live model | Scope | Cache quotes must occur in the source. Indirect cache is empty. |
| HDR / in-vivo conditionals never trigger | Technical | Conditionals attach only to extracted triggers. Guessing experiment type is forbidden. |

1. Whether a live PMC OA CRISPR slice reproduces the median field F1

   need a local blast of a genome build without shipping the genome.
